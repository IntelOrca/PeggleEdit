# Balls

Balls are round objects. They were called Circles in older versions of PeggleEdit.

Balls are used for:
* **Pegs**: a ball with peg settings is a [peg](Pegs.md).
* **Bumpers and obstacles** that the ball bounces off.
* **Images**: set **Image** to show a picture, and turn off **Collidable** if the ball should pass through it.
* **Moving other objects**: an invisible ball can carry a movement that other objects follow. See [Advanced Movement](AdvancedMovement.md).

**Radius** sets how big the ball is for bouncing. Turn on **Collision** on the **View** tab to see it.

A ball with no image and no peg settings is drawn using its **Solid Color** and **Outline Color**.
