# Planned Features

Ideas for future versions of PeggleEdit:

* Grouping objects.
* Rotating objects with the mouse.
* Showing only some kinds of object, such as only pegs.
* Drawing all brick types, and the rotation and scale of polys, as the game does.

Have an idea? Suggest it on the [issues page](https://github.com/IntelOrca/PeggleEdit/issues).
